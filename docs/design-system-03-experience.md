## 01 Motion Language
**动效语言**

<br/>

### 设计原则

**水墨意境 · 自然流动**

- 缓动曲线：Cubic Bezier (0.4, 0.0, 0.2, 1.0)
- 时长：200-400ms（快速响应）
- 风格：柔和、自然、不突兀

<br/>

### 核心动效

**水墨扩散 Ink Diffusion**

```
用于：页面转场、卡片展开
效果：从中心点向外扩散，如墨滴入水
时长：400ms
曲线：ease-out
```

**茶烟上升 Tea Steam**

```
用于：加载状态、等待提示
效果：轻盈上浮，渐隐消失
时长：2000ms 循环
曲线：ease-in-out
```

**卡片浮动 Card Float**

```
用于：卡片悬停、选中状态
效果：轻微上浮 + 阴影加深
位移：2px
时长：200ms
曲线：ease-out
```

**节气转场 Solar Term Transition**

```
用于：节气页面切换
效果：横向滑动 + 渐变过渡
时长：300ms
曲线：ease-in-out
```

<br/>

### 微交互

**按钮点击**

```
效果：缩放 0.98 + 透明度 0.8
时长：100ms
反馈：触觉震动（iOS）
```

**收藏动画**

```
效果：心形图标放大 1.2x → 缩回 1.0x
时长：300ms
颜色：灰色 → 烫金色
```

**加入购物车**

```
效果：商品图片飞入购物车图标
轨迹：贝塞尔曲线
时长：500ms
```

<br/>

### 页面转场

```
Push:  从右侧滑入（300ms）
Pop:   向右侧滑出（300ms）
Modal: 从底部上滑（400ms）
Fade:  淡入淡出（200ms）
```

## 02 Dark Theme
**夜茶模式**

<br/>

### 色彩映射

```
Light Mode          →  Dark Mode
─────────────────────────────────
米白 #F7F4EE        →  墨黑 #0D0F0E
宣纸灰 #E7E2D9      →  深灰 #151918
炭黑 #1A1A1A        →  米白 #F7F4EE
墨绿 #1E3A32        →  烫金 #C6A56B
松针绿 #355B4C      →  米灰 #A8A296
```

<br/>

### 深色模式特性

**夜间茶室氛围**

- 背景：纯黑 #0D0F0E（OLED 友好）
- 卡片：深灰 #151918（微弱对比）
- 强调色：烫金 #C6A56B（温暖点缀）
- 文字：米白 #F7F4EE（柔和不刺眼）

<br/>

### 组件适配

**按钮**

```
Primary:
- 背景：烫金 #C6A56B
- 文字：墨黑 #0D0F0E

Secondary:
- 边框：米灰 #A8A296
- 文字：米白 #F7F4EE
```

**卡片**

```
背景：深灰 #151918
边框：#2A302D
阴影：0 2px 12px rgba(0,0,0,0.6)
```

**导航栏**

```
背景：墨黑 #0D0F0E
分割线：#2A302D
选中色：烫金 #C6A56B
```

<br/>

### 图片处理

```
亮度：降低 10%
对比度：提升 5%
滤镜：轻微暖色调
```

<br/>

### 切换动画

```
效果：渐变过渡 + 色彩插值
时长：400ms
曲线：ease-in-out
保存：用户偏好持久化
```

## 03 Brand Atmosphere
**品牌氛围**

<br/>

### 山水纹理

**应用场景**

```
- 启动页背景
- 茶文化页面
- 品牌故事页面
- 空状态插图
```

**设计规范**

```
风格：水墨写意，留白为主
色调：墨绿 + 宣纸灰
透明度：10-30%（不抢主体）
位置：背景层，不影响可读性
```

<br/>

### 宣纸材质

**质感表现**

```
纹理：细腻纸纹
颜色：米白 #F7F4EE
应用：卡片背景、页面底色
效果：温润、手工感、东方美学
```

<br/>

### 茶烟元素

**动态装饰**

```
场景：加载状态、空闲动画
效果：轻盈上升的烟雾
颜色：半透明白色
速度：缓慢飘动（2-3s 循环）
```

<br/>

### 留白逻辑

**东方美学核心**

```
原则：
- 宁可留白，不可拥挤
- 重要内容周围留足呼吸空间
- 页面顶部和底部超大留白
- 文字行间距 1.6-1.8x

示例：
┌─────────────────────────┐
│                         │  ← 48px 留白
│                         │
│      李记·TEA            │
│                         │
│   一杯好茶，陪你度过      │
│      美好时光            │
│                         │  ← 32px 留白
│                         │
│   [茶品推荐]             │
│                         │
└─────────────────────────┘
```

<br/>

### 茶诗文排版

**文化底蕴展现**

```
字体：思源宋体
字号：18-22px
行高：2.0x（超大行距）
对齐：居中或左对齐
颜色：墨绿 #1E3A32
背景：宣纸纹理

示例：
    春风拂面茶香来
    一盏清茗慰平生
```

<br/>

### 节气视觉

**24 节气主题**

```
每个节气配色：
- 立春：嫩绿 #7FB069
- 谷雨：青绿 #52796F
- 立夏：翠绿 #84A98C
- 白露：银灰 #CAD2C5
- 霜降：金黄 #C6A56B
- 冬至：墨蓝 #2F3E46

视觉元素：
- 节气插画（极简线条）
- 节气诗词
- 应季茶品推荐
```

## 04 Accessibility
**无障碍设计**

<br/>

### 色彩对比

```
文字对比度：
- 主要文字：4.5:1 以上
- 次要文字：3:1 以上
- 大标题：3:1 以上

通过 WCAG AA 标准
```

<br/>

### 触达区域

```
最小触达：48×48px
按钮高度：48px（主要）/ 40px（次要）
图标按钮：44×44px 以上
```

<br/>

### 语义标注

```
所有图标按钮：添加 tooltip
导航项：标记选中状态
表单：清晰的 label 和 hint
错误提示：明确的文字说明
```

<br/>

### 屏幕阅读器

```
图片：提供 alt 描述
按钮：语义化命名
导航：逻辑顺序
焦点：清晰的焦点指示
```
